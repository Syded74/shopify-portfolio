# Shopify Portfolio

A portfolio website showcasing Shopify projects and customizations.

## Features
- Clean, responsive design
- Dark mode support
- Project showcase with live links
- Mobile-optimized

## How to customize

1. **Edit your name and intro**: Open `index.html` and replace `[Your name]` and update the lead text.
2. **Add projects**: Duplicate the `<section class="proj">` block and update:
   - Project image (`src="styleup.jpg"`)
   - Project name (`<h2>`)
   - Description
   - Tools used
   - Store link
3. **Update contact email**: Replace `you@example.com` with your email.
4. **Add project images**: Place `.jpg` or `.png` files in the root directory.

## Deploy to GitHub Pages

Your site is already set up to deploy automatically:

1. Go to your repository settings
2. Navigate to **Settings > Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose **main** branch and **root** folder
5. Click **Save**

Your site will be live at: `https://Syded74.github.io/shopify-portfolio/`

## Making the repo public

To make your repository public (so others can see it):

1. Go to **Settings** (gear icon at top right)
2. Scroll to **Danger Zone**
3. Click **Change visibility**
4. Select **Public** and confirm

Then enable GitHub Pages as described above.
